## Why are components important in React?

Components are important in React because they make the UI:
- **Reusable** — one component can be used in many places without rewriting the code.
- **Organized** — each part of the UI is separated into smaller building blocks.
- **Easier to maintain** — if something changes, we only update one component instead of the whole application.
- **Dynamic** — components can receive props, so they can display different content without changing the component code.

React applications look like LEGO — each component is a small piece that can be combined to build bigger interfaces.
