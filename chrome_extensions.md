# Developer Productivity Chrome Extensions

## Extensions Installed and Why

### 1. React Developer Tools
- Helps inspect React components in the browser
- Shows props, state, and component structure clearly
- Very useful for debugging UI behavior

### 2. Redux DevTools
- Displays the Redux store and state changes over time
- Allows time-travel debugging to replay actions
- Helps verify reducer and action behavior

### 3. JSON Viewer
- Automatically formats JSON responses from APIs
- Makes data easier to read and debug
- Useful when working with backend or external data

### 4. Lighthouse (Built into Chrome DevTools)
- Audits web app performance, accessibility, and SEO
- Shows areas for improvement in loading speed and user experience
- Helpful for building production-ready apps

## What I Learned

I learned how powerful browser tools are when developing React apps.  
Before this, I inspected only HTML/CSS, but now I can:

- Check component props and state live
- Track state updates in Redux
- Debug API data more easily
- Evaluate performance like a real front-end engineer

These tools make it much faster to find issues and understand what is happening in the app.
