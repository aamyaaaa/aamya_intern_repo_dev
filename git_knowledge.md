# Git Knowledge - My Learnings

## Have I used Git before?
Yes, I have used Git for various university projects and personal projects. I mainly used GitHub to push code and manage repositories.

## Which Git client did I choose and why?
I chose to use the Git command line and Git integration in VS Code. The command line provides full control, while VS Code makes it easier to visually see changes and commit quickly.

## Most interesting thing I learned today
I learned about checking the Git version and confirming the installation. It is interesting how Git integrates across different tools like VS Code to track changes seamlessly.
