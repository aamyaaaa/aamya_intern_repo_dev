# VS Code Productivity Notes

## My Top 10 VS Code Shortcuts (macOS)

### Navigation

1. **Command Palette**  
   `Cmd + Shift + P`  
   Open almost any VS Code command from one place. I use this instead of clicking through menus.

2. **Quick Open File**  
   `Cmd + P`  
   Jump to any file in the project by typing its name. Much faster than browsing the sidebar.

3. **Go to Symbol in File**  
   `Cmd + Shift + O`  
   Quickly jump to a function, component, or variable inside the current file.

### Editing (including multiple cursors)

4. **Add Multiple Cursors with Mouse**  
   `Option + Click`  
   Adds a cursor wherever I click. Great for editing the same thing on many lines.

5. **Add Cursor Below**  
   `Cmd + Option + ↓`  
   Adds another cursor on the line below. Useful for editing columns of similar code.

6. **Select Next Occurrence**  
   `Cmd + D`  
   Selects the next matching word/phrase and adds it to the selection. Perfect for renaming repeated variables or props.

7. **Toggle Line Comment**  
   `Cmd + /`  
   Quickly comment or uncomment the selected line(s) without manually typing `//`.

### Debugging

8. **Start / Continue Debugging**  
   `F5`  
   Runs the debugger for the current launch configuration.

9. **Toggle Breakpoint**  
   `F9`  
   Quickly add or remove a breakpoint on the current line.


### Terminal

10. **Toggle Integrated Terminal**  
    `Ctrl + \`` (backtick)  
    Open or hide the built-in terminal without leaving VS Code.


## Reflection

### Which shortcuts will be most useful in my daily work?

The shortcuts I expect to use the most are:

- **`Cmd + P` (Quick Open)** and **`Cmd + Shift + P` (Command Palette)**  
  These help me move around the project and run commands without touching the mouse. For bigger React or Node projects, this saves a lot of time.

- **Multiple cursor shortcuts**  
  - `Option + Click`  
  - `Cmd + Option + ↓`  
  - `Cmd + D`  
  These are especially useful when I need to update similar code in many places (for example, changing prop names, classNames, or repeated text).

- **`Cmd + /` (Toggle comment)**  
  I use this constantly while debugging or experimenting with different pieces of code.

- **`Ctrl + \`` (Toggle terminal)**  
  Since I often run `npm run dev`, tests, or Git commands, having the terminal inside VS Code and being able to open it quickly keeps everything in one place.

### How can keyboard shortcuts improve my productivity?

Keyboard shortcuts improve productivity by:

- Reducing context switching between mouse and keyboard.
- Making navigation much faster in large projects (no need to click through many folders).
- Speeding up repetitive edits with multiple cursors instead of changing each line manually.
- Keeping me “in the flow” while coding, because I don’t have to stop and search for buttons or menu options.
- Helping me debug faster by quickly adding breakpoints and starting/stopping the debugger.

Over time, using these shortcuts will make my work feel smoother and less tiring, especially during longer coding sessions.
