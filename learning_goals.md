# My Learning Goals

## What do you hope to learn from this internship?

During this internship, I want to learn how real developers collaborate to build and ship features.  
I’ve worked on university projects before, but Focus Bear gives me the chance to be part of a real product used by real users. I want to understand:

- How tasks are planned and tracked
- How code reviews work
- How feedback improves the product
- How releases are handled in a professional environment

I also want to improve my confidence with React and JS while working on actual features that help users with productivity and wellbeing.


## What skills are you most excited to develop?

I am most excited to strengthen my frontend engineering and web development skills, especially:

- React (components, state management, hooks)
- Writing testable, scalable code
- Debugging real user issues

One thing I am really excited about is learning how to turn UI designs into working features.

## What do you think you can contribute to the team?

As a Web Development Intern, I can contribute by actively supporting the development and improvement of Focus Bear’s web experience. Specifically:

- Building and enhancing React components that follow best practices
- Testing and documenting features to ensure smooth functionality
- Contributing ideas that help make the product more intuitive for users

I’m a strong communicator and quick learner, and I take initiative to solve problems independently while still asking for feedback when needed. I enjoy collaborating with others, and I’m dedicated to delivering high-quality code that supports the team’s goals.


## What is one area you feel less confident in that you’d like to improve?

I sometimes hesitate when writing code because I feel scared of breaking things or choosing the “wrong” solution.  
For example, when implementing authentication in a university project, I felt unsure about best practices.

This internship will help me:

- Improve my ability to debug independently
- Write cleaner, well-structured code
- Trust myself more during development

I want to become less afraid of taking technical decisions.

## What does success in this internship look like for you?

Success would be:

- Completing real tasks independently with confidence
- Seeing my work live in the Focus Bear product
- Receiving positive feedback from the team on code quality
- Growing into a developer who can join any frontend team after graduation

Most importantly, success means feeling proud of my progress and knowing that what I built genuinely helped users develop healthier habits and balance their lives.
