# Unit Testing with Jest 

## Why is automated testing important in software development?

Automated testing helps maintain software quality by:
- Catching bugs early before they reach production.
- Ensuring new changes do not break existing features (prevent regressions).
- Making refactoring safer and more confident.
- Reducing manual testing time and effort.
- Improving code reliability and stability for users.

## What did I find challenging when writing my first Jest test?

- Understanding how to structure test files and where they should be located.
- Figuring out the syntax like `test()` and `expect()`.
- Making sure Jest is configured properly in the React environment.
- Learning how to run tests and interpret the results.

But once the first test works, it becomes much easier to write more tests.
