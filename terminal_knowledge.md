# Terminal Setup & What I Learned

## Which terminal client did I choose, and why?

I am using the built-in macOS **Terminal** with **zsh**.  
I chose it because it already works well with Git and Node.js, and it integrates smoothly with VS Code.  
This setup keeps things simple while I continue learning command-line tools.

## Customizations I made

To make my workflow faster and more comfortable, I updated a few things:

- Changed the theme to **dark mode** so it’s easier on my eyes
- Confirmed **zsh** is my default shell
- Added some helpful command shortcuts (aliases) such as:

alias g="git"
alias gs="git status"
alias ll="ls -la"

These small changes reduce mistakes and make repeated commands quicker to execute.

## Most useful command I learned

git status

Why it’s useful:
- It shows which files I have modified
- Reminds me what is staged for commit
- Shows which branch I’m currently working in

This command helps me feel more in control of my work before pushing anything to GitHub.

## Final Thoughts

Setting up the terminal properly made development feel smoother and more professional.  
It saves time, helps prevent confusion, and gives me more confidence while working on real projects.  
Slowly, I’m getting more comfortable using the command line and I actually enjoy it now!
